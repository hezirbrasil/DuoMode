# ACUAS Fitness — Timer de Aulas Coletivas

Timer web para aulas coletivas, com identidade visual ACUAS Fitness (verde-limão e azul).

## Começar
Abra `index.html` em um navegador. Não é necessário instalar dependências.

## Recursos iniciais
- Cronômetro regressivo com iniciar, pausar, continuar e reiniciar.
- Configuração de duração do exercício, descanso e número de rounds.
- Indicador visual de exercício/descanso e round atual.
- Sinais sonoros e alertas visuais nos últimos 3 segundos.
- Tela cheia.
- Lista de blocos da aula com adição, remoção e reordenação.
- Salvamento local das aulas no navegador.

O banco completo de exercícios do MMA Conditioning será integrado numa etapa seguinte, após mapear os arquivos e a estrutura do banco original.
